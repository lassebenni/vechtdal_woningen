# Vechtdal woningen

Scraper for rental listings on [dewoningzoeker.nl](https://www.dewoningzoeker.nl/aanbod/te-huur) (formerly thuistreffervechtdal.nl). Runs daily via GitHub Actions and appends new listings to `data/results.json`.

[Full results](https://flatgithub.com/lassebenni/vechtdal_woningen/blob/master/data/results.json?filename=data%2Fresults.json)
